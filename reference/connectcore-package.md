# connectcore: Reusable Base for REST and WebSocket Data-Source Connectors

Shared transport base for R data-source connectors: a configurable REST
client (httr2; sync/async; retry; pluggable signing and error handling;
pagination) and an event-driven WebSocket client (auto-reconnect,
keepalive, watchdog, extensible dispatch). Connector packages extend it
instead of re-implementing transport.
