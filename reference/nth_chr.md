# The nth element of a positional array as character (or NA)

The nth element of a positional array as character (or NA)

## Usage

``` r
nth_chr(x, i)
```

## Arguments

- x:

  (list) a positional array.

- i:

  (scalar\<count in \[1, Inf\[\>) the 1-based index.

## Value

(scalar\<character \| NA\>) the element as a string, or `NA_character_`.
